## 1. AUDIT PROTOCOL & PROVENANCE STANDARD

In academic and scientific research, an empirical result is valid if and only if it is supported by complete, verifiable provenance artifacts:
1. Exact git commit identifier and environment manifest (`requirements.txt` / `conda-env.yml`).
2. Execution command line string and timestamped stdout/stderr logs.
3. Checkpoint hashes, random seed records, and raw evaluation metric dumps (`metrics.json` / `results.parquet`).
4. Re-executable data ingestion and analysis scripts.

Any numerical result lacking these artifacts cannot be claimed as an observed empirical result, regardless of how plausible it appears.
