MediRush-SafeAgent: Layered Runtime Enforcement for Healthcare-Commerce LLM Tool Execution

Sham Satish Thakare

In Peer Review at Intelligence-Based Medicine (Elsevier, Manuscript ID: IBMED-D-26-00573) • SSRN Preprint (ID: 7446543)

Abstract

Autonomous large language model (LLM) agents executing multistep tool calls in healthcare-commerce environments present catastrophic failure risks when actions cannot be reversed. In this paper, we introduce MediRush-SafeAgent, a layered runtime boundary enforcement framework designed to guarantee safety invariants during high-stakes agent execution. We establish deterministic state interception, schema-aware pre-execution guards, and out-of-band validation barriers that decouple agent decision proposals from irreversible system mutations. Empirical evaluations across clinical ordering and fulfillment scenarios demonstrate zero invariant violations with minimal latency overhead.
