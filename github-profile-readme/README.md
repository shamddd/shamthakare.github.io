### About
I conduct research on **reliable reasoning and adaptive computation for foundation models**, investigating how learning and reasoning systems make verifiable decisions when confidence proxies, reasoning trajectories, internal states, and compute budgets are imperfect or changing.

* [**recovery_eval**](https://github.com/shamddd/recovery_eval): State-matched continuation evaluation protocol measuring error recovery under frozen structural covariates. *(Submitted to IEEE BigData 2026 `BigD497`)*
