## 🌟 Featured Research & Engineering Projects

### 1. [`recovery_eval`](https://github.com/shamddd/recovery_eval)
**State-matched, provenance-aware evaluation framework for recovery behavior in language-model reasoning.**

* **Research Focus**: LLM reasoning evaluation · verifier-guided search · prospective matching · data-centric AI · reproducibility.
* **Empirical Evidence**: Evaluated on 400 genuine neural continuations from `Qwen2.5-Math-1.5B` Base vs. Instruct across 20 GSM8K evaluation problems. Measured matched recovery-specific contrast $D_{\text{recovery}} = -0.110$ (95% bootstrap CI: $[-0.240, +0.030]$).
* **Key Finding**: Under the evaluated state-matched protocol, we did not observe evidence of a recovery-specific advantage for the Instruct checkpoint over the Base checkpoint.
* **Publication Status**: IEEE BigData 2026 — Submitted / Under Review (`BigD497`)
* **Tech Stack**: Python 3.11+ · PyTorch · Hugging Face Transformers · Pytest · Tectonic TeX
