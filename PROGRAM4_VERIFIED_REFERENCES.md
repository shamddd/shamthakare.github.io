## 1. Primary References (Verified)

1. **Prezta (USENIX Security 2026)**:
   - *Title*: *Prezta: Provable Remote Execution of Zero-Trust Authorization using SNARKs*
   - *Venue*: 35th USENIX Security Symposium (August 2026)
   - *URL*: `https://www.usenix.org/conference/usenixsecurity26/presentation/prezta`
   - *Relevance*: Evaluates zkVM execution of XACML authorization policies. Program 4 evaluates multi-parent causal DAG authorization paths, NOT single-turn zkVM policy checks.

2. **Zombie (NSDI 2024)**:
   - *Title*: *Zombie: Middleboxes that Don't Snoop*
   - *Venue*: 21st USENIX Symposium on Networked Systems Design and Implementation (NSDI 2024)
   - *URL*: `https://www.usenix.org/conference/nsdi24/presentation/zombie`
   - *Relevance*: Zero-knowledge middlebox policy enforcement over encrypted traffic.

3. **zkLedger (NSDI 2018)**:
   - *Title*: *zkLedger: Privacy-Preserving Auditing for Distributed Ledgers*
   - *Venue*: 15th USENIX Symposium on Networked Systems Design and Implementation (NSDI 2018)
   - *URL*: `https://www.usenix.org/conference/nsdi18/presentation/narayanan`
   - *Relevance*: Zero-knowledge private auditing over committed transaction ledgers.

4. **A Framework for Policies over Provenance (TaPP 2011)**:
   - *Title*: *A Framework for Policies over Provenance*
   - *Venue*: 3rd USENIX Workshop on Theory and Practice of Provenance (TaPP 2011)
   - *URL*: `https://www.usenix.org/conference/tapp11/framework-policies-over-provenance`
   - *Relevance*: Theoretical framework for access control policies over data provenance graphs.

5. **zkLLM (ACM CCS 2024)**:
   - *Title*: *zkLLM: Zero-Knowledge Proofs for Large Language Models*
   - *Venue*: ACM Conference on Computer and Communications Security (CCS 2024)
   - *URL*: `https://arxiv.org/abs/2404.16109`
   - *Relevance*: Verifies neural network weight inference correctness in ZK.
