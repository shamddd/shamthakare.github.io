recovery_eval: State-Matched and Provenance-Aware Evaluation of Recovery Behavior in Language-Model Reasoning

Sham Satish Thakare

Abstract

Evaluating whether instruction-tuned language models possess intrinsic self-correction capability requires distinguishing true error recovery from random trajectory sampling. In this paper, we introduce a state-matched contrast protocol pairing verifier-defined recovery states with prospectively matched reference control states across 400 continuations of Qwen2.5-Math 1.5B. We measure a matched recovery contrast D_recovery = -0.1100 (95% CI [-0.240, +0.030]), demonstrating that instruction checkpoints display no recovery-specific advantage over base checkpoints on single-step arithmetic errors.
