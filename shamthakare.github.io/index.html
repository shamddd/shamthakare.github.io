In June 2024, I graduated with a B.Tech. in Artificial Intelligence and Data Science from APCOER Pune with a cumulative GPA of 8.70 / 10.00.

Uncertainty-Weighted Credit Assignment in LM RL (ear_grpo_reasoning)

MediRush-SafeAgent: Multi-Stage Tool Execution Safety
Multi-stage runtime interception framework guaranteeing 100% safe task completion and 0% policy violations for healthcare-commerce agents. [Code]

State-Matched Error Recovery Evaluation (recovery_eval)
