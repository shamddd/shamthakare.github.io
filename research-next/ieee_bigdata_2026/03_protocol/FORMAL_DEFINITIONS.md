## 1. MATHEMATICAL DEFINITIONS

1. **Reasoning State ($s$)**: A prefix trajectory of reasoning steps $s = (q, t_1, t_2, \dots, t_k)$ generated from problem query $q$.
2. **Recovery State ($S_R$)**: A reasoning state immediately following an identifiable incorrect intermediate step $t_k$ where a valid corrective continuation remains mathematically possible.
3. **Matched Control State ($S_C$)**: A non-recovery reasoning state $S_C = (q', t'_1, \dots, t'_m)$ matched to $S_R$ across explicit structural covariates $X(s)$.
4. **Continuation ($a \sim \pi(\cdot \mid s)$)**: The text/token sequence generated by policy $\pi$ following prefix state $s$.
5. **Verifier Outcome ($V(s, a) \in \{0, 1\}$)**: Objective binary correctness evaluated by an automated AST or execution sandbox verifier on state-continuation pair $(s, a)$.
6. **Continuation Value ($V_\pi(s)$)**: Expected continuation success rate $V_\pi(s) = \mathbb{E}_{a \sim \pi}[V(s, a)]$.
7. **Treatment Contrast ($C_1$)**: $C_1 = \mathbb{E}_{S_R}[V_{	ext{FULL}} - V_{	ext{PREFIX}}] - \mathbb{E}_{S_C}[V_{	ext{FULL}} - V_{	ext{PREFIX}}]$.
8. **Exposure Status**: Immutable governance state $\in \{	ext{UNSEEN}, 	ext{DEVELOPMENT\_EXPOSED}, 	ext{PILOT\_EXPOSED}, 	ext{SIMULATION\_EXPOSED}, 	ext{CONFIRMATORY\_RESERVED}, 	ext{EXCLUDED}\}$.
